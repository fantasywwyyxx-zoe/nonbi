# のんびー (nonbi)

飲みナビ：チャット型ロボット「のんびー」が、条件を聞いて近くの良い飲み屋をおすすめする PWA。
まずは池袋パイロット（144軒の実データ）で試作中。

- アプリ本体：`index.html`（単一ファイル、舞台型デザイン：全画面ロボット＋必要時だけ浮き出る選択肢）
- データ：`data/ikebukuro.json`（生成物）／原本は `data/ikebukuro-pilot-v1.md`（収録ルール・完成度・除外記録つき）
- 素材：`assets/`（マスコット切り抜き、実測で本人確認済みの店舗写真3店分）
- 出荷前チェック：`python3 tools/check.py`（全 PASS でないと出荷しない）

## TQL から引き継ぐ出荷ルール（必修）

1. **チェックを通してから出す。** 未検証の一括投入で本番を壊した事故（TQL 2026-11-01 昼）を繰り返さない。データ投入・コード変更は必ず `tools/check.py` 全 PASS → コミット → 公開 → 実機確認の順。
2. **実機が最終審。** ラボ（PCシミュレーション）の合格は合格ではない。手機サイズ＋ホーム画面追加（スタンドアロン）モードで Zoe の実機確認をもらって初めて完了。
3. **報告は結果だけ。** 何が変わったか／公開されているか／どこを押せば試せるか。内部の工程報告はしない。
4. **凍結中は勝手に触らない。** 本番への追加・変更は Zoe の明示のひと言がある時だけ。
5. **事実は盛らない。** 店舗の事実字段（評価・電話・営業時間・写真）は出典のあるものだけ。確認できないものは「未確認」と明記し、他店の代用や推測で埋めない。ロボットは DB にある店しかすすめない。

## データ運用

- 事実字段（評価・電話・営業時間・写真）は Google Places API で月次リフレッシュする設計（Place ID のみ恒常保存、内容は都度取得＝Google の規約準拠）。各 SKU 月1,000回まで無料枠があり、現規模では無料で回る。
- 人の仕事は「雰囲気タグ付け」と選店（品質ゲート：食べログ約3.5+／Google約4.2+かつ口コミ十分／隠れ名店の人工精選、そのいずれか＋口碑崩壊の店は除外）。
- 地図ボタンは TQL 方式：押すたびに Google／Apple／Yahoo を選ばせる（Yahoo は日本語の店名で検索）。

## ロードマップ（合意済み）

- パイロット：池袋 144軒（済）→ 目標 150 へ次批候補から補充
- 次エリア：新宿 200／新橋 150／上野・御徒町 120／吉祥寺 100
- 一期：簡易アプリ内マップ（入池店ピン＋小カード）、飲みログ
- 後期：コミュニティ（地図の上に重ねる）、パーソナライズ L2/L3
